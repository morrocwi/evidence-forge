# HARC Functional Source Layer Stack

This project applies the reusable `schemas/functional-source-layer-stack.md` to the AI-human-potential preprint.

The aim is to make literature review a **layered conversation** rather than a flat bibliography.

## L1 — Taxonomy / discovery vocabulary

For each P1–P10 proposition, first identify the vocabularies used by neighbouring fields.

Examples of vocabulary families already relevant to this project:

- problem ownership / open inquiry / authentic learning
- prompt sensitivity / semantic perturbation
- interactional expertise / contributory expertise
- boundary crossing / problem framing
- cognitive offloading / automation dependence
- self-regulated learning / metacognition
- epistemic vigilance / source evaluation
- retention / transfer / delayed assessment
- capability / conversion factors / epistemic agency
- entrustment / relational trust

**Output:** search vocabulary, neighbour terms, rejected synonyms.

**Never use L1 alone as evidence for P1–P10.**

---

## L2 — Conceptual reference / field orientation

Use high-quality reviews, handbooks and reference works to answer:

- What does the field already distinguish?
- Which construct is established?
- Which adjacent term is not equivalent?
- What debates or boundary conditions already exist?

**Output:** construct-lineage notes and prior-work boundary.

For HARC this layer is especially important for preventing new labels from duplicating:
- retention
- transfer
- cognitive offloading
- self-regulation
- distributed cognition
- entrustment

---

## L3 — Primary / original sources

This is the main evidential layer for proposition-level support/challenge.

For every source bearing on P1–P10, record:

- exact study/theory
- population/task/domain
- assistance condition
- outcome timing
- whether AI remained available
- direct versus transfer outcome
- limitation

**Output:** Glosa citation card + proposition relation.

---

## L4 — Identity / provenance

Resolve every central source against stable scholarly metadata.

Minimum:
- DOI / persistent identifier where available
- title
- authors
- year
- venue
- version / preprint / published status

**Output:** provenance row.

A DOI match only verifies identity, not the claim.

---

## L5 — Citation / knowledge graph

Use graph traversal for:

- backward citation chaining
- forward citations
- critiques
- replications
- papers that cite two otherwise separate literature families
- bridge works connecting learning, HCI, psychology and epistemology

**Output:** citation-chain record and candidate challenge sources.

Graph centrality or citation count is discovery information only.

---

## L6 — Index / coverage corroboration

Use major scholarly indexes or field-specific databases to audit:

- whether the search is trapped in one disciplinary database
- whether key source families were missed
- whether sources sit in education, psychology, HCI, philosophy, management or professional learning literatures

**Output:** coverage audit.

This layer does not upgrade evidence strength.

---

## L7 — Claim-level verification

Glosa source-first rule applies.

A proposition/source relation can move from `PENDING_CHECK` to `VERIFIED` only when:

1. original source was opened;
2. exact passage / locator is recorded;
3. the manuscript claim does not exceed source scope;
4. source identity/version is resolved;
5. contradictory evidence is recorded where relevant;
6. independent claim-match route passes.

## Layered conversation object

Every literature row should answer:

| Field | Question |
|---|---|
| proposition | Which P1–P10 claim is this talking to? |
| architecture node | Which node does it bear on? |
| source layer | What function is this source/system serving? |
| relation | SUPPORTS / CHALLENGES / EXTENDS / PENDING |
| what it sees | What distinction does the source make visible? |
| what it misses | What part of our trajectory is outside its scope? |
| exact bearing | Which sentence/relationship can it legitimately support? |
| boundary | Where does the relation stop? |
| next layer | What must be checked next? |

This converts literature review from "Paper A says X; Paper B says Y" into a traceable conversation across source functions.
