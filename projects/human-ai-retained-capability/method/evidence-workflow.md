# Evidence workflow

This project does not invent a new review method. It delegates review discipline to **glosa LRS**.

## Binding workflow

1. Freeze the paper architecture before searching.
2. Run a separate search episode for the focal proposition / falsifier.
3. Record support and challenge query families.
4. Acquire the original source.
5. Read the source directly.
6. Create a source-first citation card with exact passage and locator.
7. Map the source to architecture nodes using only:
   - SUPPORTS
   - CHALLENGES
   - EXTENDS
8. Keep PENDING when the relation is not yet supportable.
9. Run claim-match verification through an independent route before calling a citation VERIFIED.
10. Preserve null, adverse and contradictory findings.
11. Feed the verified subset into the claim–evidence matrix.
12. Send revision recommendations back to the preprint; do not let the evidence workspace silently rewrite the conceptual source of record.

## Review label

Initial mode: **TARGETED_SEARCH / architecture-first comparative review**, not systematic review.

This may change only if the human author deliberately freezes and executes a systematic-review protocol.

## Citation rule

A bibliography entry copied from the preprint is a discovery lead, not verified evidence. The original source must be opened.
