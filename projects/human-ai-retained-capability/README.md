# Human–AI Retained Capability — Theory-Building Project

## Genre

**Conceptual / Theory-Building Paper**, with a planned path toward a **formal and executable theory**.

This project does not treat the literature review as the endpoint. Evidence is used to build, challenge, delimit, and eventually formalize a theory of what remains with a human after AI assistance is reduced or removed.

## Core distinction

~~~text
ASSISTED PERFORMANCE
        ≠
RETAINED HUMAN CAPABILITY
~~~

The focal question is not only whether AI improves performance while it is present, but what capability remains attributable to the human after assistance is withdrawn, reduced, or transformed.

## Working theory path

~~~text
AI ASSISTANCE
      ↓
SEMANTIC / COGNITIVE CHANGE
      ↓
WITHDRAWAL / RETURN
      ↓
RETAINED HUMAN CAPABILITY
      ↓
HUMAN CONVERSION
      ↓
AUTONOMOUS OR TRANSFERRED CAPABILITY
~~~

Every arrow is provisional until supported by mechanism, evidence, boundary conditions, and falsifiers.

## Evidence discipline

Every statement must remain distinguishable as:

- source-derived evidence
- synthesis
- assumption
- construct
- mechanism
- proposition
- boundary condition
- rival explanation
- falsifier
- observable implication

## Project method

**Structured Search + Integrative Theory Synthesis + Claim–Evidence Matrix + Citation Chaining + Citation Audit + Theory–Evidence–Falsifier Matrix**

This is not labelled a systematic review unless the search and screening design later satisfies that standard.
