# L3 — Primary / original sources

## Purpose

Hold the proposition-bearing scholarly objects that must be opened directly.

Current first-pass source IDs are maintained in:
- `../source-status-first-pass.md`
- `../citation-matrix.md`

## Minimum extraction fields

| Field | Required |
|---|---|
| source_id | yes |
| proposition | yes |
| source_type | yes |
| population / corpus | where applicable |
| task / domain | where applicable |
| assistance condition | where applicable |
| comparator | where applicable |
| immediate outcome | where applicable |
| delayed outcome | where applicable |
| transfer outcome | where applicable |
| exact locator | yes before VERIFIED |
| supports | yes |
| does_not_support | yes |
| limitations | yes |
| relation | SUPPORTS / CHALLENGES / EXTENDS / PENDING |

## Guard

Do not infer delayed learning from immediate task performance.  
Do not infer transfer from same-task retention.  
Do not infer human capability from a joint human–AI artifact.
