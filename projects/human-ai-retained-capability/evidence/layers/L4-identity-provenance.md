# L4 — Identity / provenance

## Purpose

Ensure that the source being discussed is the correct scholarly object and version.

## Record

| Source ID | DOI / identifier | Published / preprint | Version resolved? | Metadata checked? | Notes |
|---|---|---|---|---|---|
| E01–E22 | see source-status-first-pass.md | mixed | pending per source | first-pass only | migrate to one-row-per-source audit |

## Required checks before VERIFIED

- title and author match
- year/venue match
- DOI or persistent identifier resolves where available
- preprint vs published version is explicit
- correction/retraction/version status checked where relevant

## Guard

Identity validation answers **"which object is this?"**  
It does not answer **"is its claim correct?"**
