# Evidence layers

Each file in this directory records one **source function**. These are not authority rankings.

```text
L1 taxonomy/discovery
L2 conceptual orientation
L3 primary evidence
L4 identity/provenance
L5 citation graph
L6 coverage/index corroboration
L7 claim verification
```

A central source may appear in several layers because the same scholarly object can be used for more than one function, but every use must state the function explicitly.

The final manuscript may cite L2 or L3 sources as appropriate. L4–L6 primarily support discovery, provenance and coverage. L7 determines whether the exact manuscript claim is supported.
