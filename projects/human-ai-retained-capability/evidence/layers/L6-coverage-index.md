# L6 — Coverage / index corroboration

## Purpose

Prevent the review from becoming a monoculture of one database or discipline.

## Disciplinary coverage to audit

- education / learning sciences
- psychology / cognitive science
- HCI / human–AI interaction
- AI / NLP
- philosophy / epistemology
- sociology of expertise
- management / organizational learning
- professional / medical education for entrustment

## Coverage questions

- Did at least one appropriate source system for each relevant discipline get searched?
- Are local terminology differences masking the same problem?
- Did challenge searches run outside the discipline that generated the proposition?
- Are non-English / regional literatures materially relevant?
- Are seminal and current sources both represented?

## Guard

Index inclusion is not a quality certificate.  
A prestigious database cannot upgrade a weak claim-source match.
