# Prior-work boundary check

The present analysis overlaps intentionally with established work on learning, retention, transfer, cognitive offloading, automation, metacognition, distributed cognition, and human–AI collaboration.

That overlap must be made explicit before any novelty claim is considered.

## Established work that must be credited

### Learning retention and transfer

Existing learning science already distinguishes immediate performance, retention, and transfer. The project must not rename these distinctions as if they originated here.

### Cognitive offloading

Existing theory already explains how external tools can reduce internal cognitive work while improving task completion.

### Automation and skill degradation

Automation literature already examines reliance, automation bias, complacency, and possible skill loss.

### Metacognition and calibration

Confidence and objective capability are already known to diverge in many settings. Any AI-specific calibration claim must be demonstrated rather than assumed.

### Distributed / extended cognition

Some theories treat tools as part of the cognitive system. The project therefore cannot assume that unaided individual capability is always the only valid unit of analysis.

### Human–AI teaming and augmentation

Immediate assisted performance is already studied extensively. The project must show why post-assistance human capability is a distinct theoretical and measurement problem.

## What remains to be examined here

Rather than claiming the prior ideas as new, the project examines how they interact when AI assistance creates a measurable sequence across:

- baseline human-only capability;
- AI-assisted performance;
- withdrawal / Human Return;
- delayed retained capability;
- transfer to a new condition;
- calibration between perceived and observed capability.

## Boundary test for contribution

The project earns a stronger theoretical contribution only if it can show at least one of the following:

1. a relation not already specified by established theory;
2. a mechanism that changes predictions in AI-assisted settings;
3. a boundary condition that explains heterogeneous post-assistance outcomes;
4. a measurement architecture that prevents assisted output from being misattributed to the human;
5. falsifiable predictions that differ from existing accounts.

The reader should infer the value of the configuration from evidence, formal relations, and tests rather than from a novelty label.
