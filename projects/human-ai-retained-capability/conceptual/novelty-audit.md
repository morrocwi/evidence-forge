# Novelty audit

## Reviewer attack to anticipate

> "This is just learning retention, transfer, cognitive offloading, automation dependence, or extended cognition with new labels."

That criticism must be treated as plausible until disproven.

## Audit questions

1. Does `Retained Human Capability` add anything beyond retention / independent competence?
2. Is `Human Return` theoretically necessary or merely a measurement transition?
3. Is `Human Conversion` distinct from internalization, transfer, appropriation, or skill acquisition?
4. Does the assisted-versus-retained distinction change predictions or only terminology?
5. Does the model specify moderators or mechanisms that existing theories do not combine?
6. Does the model yield new falsifiable tests?
7. Is the chosen unit of analysis explicitly defended against system-level accounts?

## Candidate contribution levels

### Level A — measurement distinction
Separate AI-assisted task performance from independently retained capability.

### Level B — integrative theory
Explain divergence using mechanisms drawn from offloading, feedback, reconstruction, calibration, and transfer.

### Level C — formal theory
Specify relations, moderators, and observable implications in a falsifiable model.

### Level D — executable theory
Encode the theory as a reproducible test harness or benchmark protocol.

## Rule

If an established framework already subsumes a construct or relation, import and cite it rather than renaming it.
