# Formal definitions

## D1 — Assisted performance

For task t, human h, assistance condition a:

~~~text
PA(h,t,a) = observed performance while materially assisted by AI
~~~

## D2 — Retained human capability

~~~text
RHC(h,t,τ,w) = observed human performance on task t
               after assistance withdrawal/reduction w
               at delay τ
~~~

The measurement condition must specify what tools remain available.

## D3 — Assisted–retained gap

~~~text
G(h,t) = PA(h,t,a) - RHC(h,t,τ,w)
~~~

Interpretation depends on common scale and task comparability.

## D4 — Transfer

~~~text
TR(h,t') = post-assistance performance on a defined transfer task t'
~~~

where t' differs from the assisted task along declared dimensions.

## D5 — Calibration

~~~text
C = f(perceived capability, observed capability)
~~~

The exact calibration function remains to be chosen.

## Definition rule

No symbol should be used in propositions until its empirical interpretation is specified.
