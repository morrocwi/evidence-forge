# Formal notation

Notation is provisional. Symbols must not outrun the conceptual definitions.

| Symbol | Meaning |
|---|---|
| H0 | baseline human-only capability |
| A | AI assistance condition / intensity |
| PA | observed AI-assisted performance |
| HR | Human Return test condition |
| RHC | retained human capability after withdrawal / reduction |
| TR | transfer performance |
| C | calibration between perceived and observed capability |
| D | degree of delegation / offloading |
| E | active engagement / reconstruction |
| F | feedback quality |
| X | contextual / boundary variables |

## Basic distinction

~~~text
PA != RHC
~~~

unless a specific design establishes the relation.

## Candidate change quantities

~~~text
Assisted gain:      ΔA = PA - H0
Retained gain:      ΔR = RHC - H0
Transfer gain:      ΔT = TR - H0_transfer
Assisted-retained gap: G = PA - RHC
~~~

These quantities are placeholders, not validated metrics.
