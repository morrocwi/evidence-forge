# Structured literature search strategy

## Purpose

Build a theory-relevant evidence base rather than a literature census.

## Literature families

Search at minimum across:

1. human–AI interaction
2. cognitive offloading
3. automation and skill degradation
4. learning transfer and retention
5. metacognition and calibration
6. intelligent tutoring / AI-supported learning
7. distributed / extended cognition
8. human agency and autonomy
9. human–computer collaboration
10. measurement of post-assistance performance

## Search principles

- Search each construct family independently before combining them.
- Preserve exact search strings and dates in `search-log.md`.
- Use backward citation chaining for seminal works.
- Use forward citation chaining for current developments and critiques.
- Prefer primary studies for empirical claims.
- Prefer authoritative reviews/meta-analyses for state-of-field claims.
- Explicitly search for null, adverse, reversal, and dependency effects.

## Important distinction

This project uses a **structured search** for theory construction. It must not be described as a systematic review unless the protocol later includes a reproducible exhaustive search, screening procedure, inclusion/exclusion workflow, and appropriate reporting.
