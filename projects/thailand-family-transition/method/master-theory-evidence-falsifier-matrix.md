# Master Theory–Evidence–Falsifier Matrix

## Purpose

This is the central adversarial-control file for the conceptual paper.

It does not ask whether an idea is attractive. It asks whether each relation can survive:

- construct separation;
- measurement;
- positive evidence;
- counterevidence;
- rival explanations;
- causal-direction attack;
- cross-context transport;
- specification changes;
- harm analysis;
- opportunity-cost comparison;
- system-capacity feedback;
- prospective prediction;
- explicit kill criteria.

Decision labels:

- **RETAIN** — sufficiently supported for the present conceptual paper.
- **RETAIN / NARROW** — useful but wording or scope must remain restricted.
- **OPEN** — analytically plausible, but not yet strong enough for a substantive conclusion.
- **COLLAPSE** — merge with another variable if distinct value is not demonstrated.
- **REMOVE** — drop if the stated falsifier is met.

# L. Whole-architecture kill tests

The entire architecture should be **substantially simplified** if any of the following patterns emerge:

## L1. Construct redundancy

If:

\[
Access,\ Capability,\ Meaning,\ FeltSafety,\ TemporalFeasibility
\]

cannot be separated empirically, merge them.

## L2. Simpler-rival dominance

If any simpler model:

\[
EconomicOnly,\ CapacityOnly,\ AccessOnly,\ RelationshipSkillsOnly,\ CultureOnly
\]

explains and predicts the relevant outcomes equally well after complexity penalty, prefer the simpler model.

## L3. Causal reversal

If proposed mechanisms repeatedly disappear under longitudinal/causal analysis, remove the arrows and retain only descriptive associations.

## L4. Specification fragility

If central claims appear only under one arbitrary mathematical/statistical specification, treat them as unstable.

## L5. Transport failure

If relations repeatedly fail across cultural, socioeconomic or geographic contexts and no coherent moderators explain the variation, narrow scope rather than claim generality.

## L6. Safety failure

If an intervention improves engagement or relationship persistence while worsening:

\[
Safety,\ Autonomy,\ Confidentiality
\]

the intervention fails.

## L7. Economic dominance by alternatives

If the same resource spent on:

\[
Childcare,\ Cash,\ MentalHealth,\ Capacity,\ Protection,\ Parenting
\]

produces consistently larger valued outcomes than the proposed civil-society layer, the proposed allocation should not be preferred.

## L8. Capacity failure

If navigation mainly creates queues because receiving services are saturated, connectivity cannot be treated as the primary solution.

## L9. Equity failure

If average outcomes improve while disadvantaged groups experience worse access, safety, burden or waiting, the architecture fails its equity constraint.

## L10. Meaning/autonomy failure

If “cultural adaptation” improves uptake by increasing coercive conformity or suppressing individual voice, it fails even if attendance rises.

# M. Positive-evidence threshold

A central relation should be considered comparatively strong only when several independent routes converge:

\[
ConceptualLineage
+
CurrentSynthesis
+
DirectEmpiricalEvidence
+
CounterevidenceSurvived
+
CrossContextReplication
\]

Where possible, also require:

\[
ProspectivePrediction
+
IndependentReplication
\]

The project should not count multiple citations from the same methodological tradition as full triangulation.

# N. Current weakest links

After all stress tests to date, the most important unresolved relations are:

1. **Meaning coherence** — whether it is empirically distinct from existing well-being/identity/belonging constructs.
2. **Experienced access / felt safety** — whether they add predictive value beyond established access, trust and confidentiality constructs.
3. **Temporal feasibility** — how best to measure it and whether it predicts participation beyond motivation and socioeconomic status.
4. **Known return route + trigger** — whether it is more effective and cheaper than scheduled universal follow-up.
5. **Culturally embedded entry point** — whether cultural legibility/trust improves reach without reducing privacy/autonomy.
6. **Edge–node–hybrid decision rule** — whether bottleneck classification actually predicts the most cost-effective intervention.
7. **Tiered universal-light-touch + targeted-intensity model** — whether targeting saves cost without missing high-need families.
8. **Cross-level aggregation** — how family-level gains, if any, propagate to population-level outcomes.
9. **Opportunity cost** — whether the civil-society layer beats alternative uses of the same resources.
10. **Transportability** — whether the structure survives outside the Thai context and across Thai cultural groups.

These should receive priority in the next research and citation rounds.

# O. Final decision rule for manuscript inclusion

A relation enters the final conceptual paper only if it meets one of three standards:

\[
StrongEvidence
+
ClearBoundary
+
NoMajorUnresolvedContradiction
\]

### Standard 2 — defensible working proposition

\[
PlausibleMechanism
+
SomeEvidence
+
ExplicitFalsifier
+
ClearLabelAsProposition
\]

### Standard 3 — useful analytic distinction

\[
PreventsConceptualCollapse

Anything else remains in the development repository but does not enter the final paper.

This keeps the internal reasoning system broader than the submitted manuscript.

# P. Round-3 adjudication update

Evidence Attack Round 3 materially narrows five previously surviving relations.

| ID | Prior working claim | Round-3 adjudication |
|---|---|---|
| P1 | family-transition contact → later support access | **Narrow:** premarital education is associated with later relationship-counselling use, but causality and extension to wider family services remain open |
| P2 | minimum sufficient rapid core | **Downgrade:** no empirically established minimum package; replace with a test of **minimum non-deferrable functions** |
| P3 | shared couple + private individual channel | **Strengthen but bound:** private individual access has strong safeguarding support in IPV/reproductive-coercion care; premarital dual-channel effectiveness still requires direct testing |
| P4 | known return route + triggered contact | **Split:** user-initiated return, transition-triggered offer and periodic checkup are different mechanisms; evidence supports continuity/repeated contact, not yet the proposed low-cost triggered model |
| P5 | edge/node/capacity decision rule | **Expand:** include availability, connectivity, capacity, quality and governance; classification remains a diagnostic proposition rather than a validated family-service algorithm |

## New kill priority

The architecture now fails if it cannot demonstrate at least one of the following problem-specific gains beyond imported parent frameworks:

1. a causal transition-contact gateway to later **appropriate** help-seeking;
2. an empirically defensible rule for what can safely be deferred under low temporal feasibility;
3. measurable safety/access gain from a private route alongside shared couple contact;
4. superior value of triggered/user-initiated return over periodic follow-up for at least some populations;
5. predictive validity of bottleneck diagnosis for selecting edge/node/capacity/governance/hybrid investment.

If none of these survives prospective testing, the conceptual paper should be reframed as an integrative application of established frameworks rather than a distinct theoretical architecture.
