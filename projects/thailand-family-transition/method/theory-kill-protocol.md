# Theory kill protocol

## Purpose

This file defines the conditions under which the working equation system should be simplified, narrowed, revised, or abandoned.

The goal is not to defend the framework. The goal is to make it possible for evidence to defeat it.

The current project already includes:

- supporting evidence;
- contradictory evidence;
- boundary conditions;
- rival explanations;
- temporal-fit stress tests;
- return/re-contact stress tests;
- capacity-aware edge/node economics;
- safety and cultural/meaning constraints.

The remaining requirements are listed below.

---

# 1. Construct-separation test

The model currently distinguishes:

\[
Availability,\ Access,\ Capability,\ Meaning,\ FeltSafety,\ TemporalFeasibility,\ Continuity,\ Opportunity
\]

These distinctions are useful only if they are empirically and conceptually separable.

Required tests:

- discriminant validity;
- convergent validity;
- factor structure;
- redundancy/collinearity;
- incremental explanatory value.

Kill rule:

\[
Construct_A \approx Construct_B
\quad\text{and adds no incremental value}
\Rightarrow
Collapse(A,B)
\]

A theory becomes weaker, not stronger, when it creates unnecessary variables.

---

# 2. Measurement-invariance test

A variable cannot be compared across cultures, groups or time merely because the same questionnaire is used.

Required:

\[
Configural
\rightarrow
Metric
\rightarrow
Scalar
\rightarrow
Longitudinal
\]

invariance where relevant.

Priority constructs:

- meaning coherence;
- felt safety;
- navigation literacy;
- family readiness;
- temporal feasibility;
- caregiver well-being.

Kill rule:

\[
MeasurementMeaning_{group1}
\neq
MeasurementMeaning_{group2}
\Rightarrow
DoNotCompareRawScores
\]

If invariance repeatedly fails, the model must permit culture-specific operationalisation rather than claiming one universal scale.

---

# 3. Causal-direction test

For every proposed arrow:

\[
X\rightarrow Y
\]

also test:

\[
Y\rightarrow X
\]

and:

\[
Z\rightarrow \{X,Y\}
\]

Examples:

\[
Navigation\rightarrow ServiceUse
\]

versus:

\[
Motivation\rightarrow Navigation+ServiceUse
\]

or:

\[
FamilyWellbeing\rightarrow HelpSeeking
\]

rather than help-seeking causing family well-being.

Required tools in later empirical work may include:

- longitudinal designs;
- DAGs;
- negative controls;
- natural experiments;
- instrumental variables where defensible;
- cross-context comparisons.

Kill rule:

If reverse causation or confounding explains the relation equally well, remove the causal arrow and retain only association.

---

# 4. Rival-model tournament

Every major explanation should compete against a simpler rival.

Minimum rivals:

\[
R_1=\text{economic constraints only}
\]

\[
R_2=\text{service capacity only}
\]

\[
R_3=\text{relationship skills only}
\]

\[
R_4=\text{health/preconception only}
\]

\[
R_5=\text{culture/norms only}
\]

\[
R_6=\text{generic access/navigation model}
\]

\[
R_7=\text{null model: no additional architecture needed}
\]

The working model survives only if it explains or predicts something that materially simpler models do not.

Kill rule:

\[
Performance(SimpleModel)
\ge
Performance(ExpandedModel)
\]

after complexity penalty

\[
\Rightarrow
PreferSimpleModel
\]

---

# 5. Risky-prediction test

The framework must make observations that could embarrass it.

Examples:

### Prediction A

If service capacity has slack and navigation is the binding barrier:

\[
ImproveEdge
\Rightarrow
ReferralCompletion\uparrow
\]

without major waiting-time deterioration.

### Prediction B

If capacity is already saturated:

\[
ImproveEdge
\Rightarrow
Demand\uparrow
+
WaitTime\uparrow
\]

unless capacity also rises.

### Prediction C

A short-horizon core should improve:

\[
Orientation,\ Navigation,\ SafetyLiteracy
\]

more reliably than:

\[
DeepRelationshipSkill
\]

### Prediction D

Cultural familiarity without autonomy/safety may increase engagement while failing to improve lived well-being.

### Prediction E

A known return route should matter most near transitions or emerging need, not equally at all times.

Kill rule:

Repeated prospective failure of distinctive predictions requires structural revision, not post-hoc reinterpretation.

---

# 6. Specification-robustness test

The mathematics must survive alternative defensible formulations.

Compare:

- additive versus multiplicative access models;
- threshold versus continuous functions;
- linear versus nonlinear effects;
- direct versus mediated paths;
- alternative barrier definitions;
- alternative outcome weighting;
- alternative lag structures.

Use:

- specification curves;
- multiverse analysis;
- independent analysts where possible.

Kill rule:

If the central result appears only under one arbitrary specification, it is not yet a robust theoretical relation.

---

# 7. Cross-context transportability test

The framework must state where it should travel and where it should not.

Test across:

- Thailand / other countries;
- urban / rural;
- high / low service capacity;
- different cultural communities;
- different income groups;
- migrant / non-migrant populations;
- different family forms;
- different life stages.

Kill or narrow rule:

\[
Effect_{contextA}\neq Effect_{contextB}
\]

does not automatically kill the whole framework.

Instead:

- identify moderator if theoretically coherent;
- narrow scope if not;
- abandon universal wording if transport fails repeatedly.

---

# 8. Fidelity–adaptation test

The model values cultural adaptation.

But unlimited adaptation can remove the mechanism itself.

Separate:

\[
CoreFunctions
\]

from:

\[
AdaptableForms
\]

Possible core functions:

- safe/private route;
- accurate navigation;
- professional boundary;
- referral continuity;
- autonomy;
- minimum safety information.

Possible adaptable forms:

- language;
- facilitator;
- venue;
- examples;
- cultural framing;
- module order;
- communication channel.

Kill rule:

If a supposedly essential component can be removed without changing outcomes across repeated tests, it is not essential.

If cultural adaptation repeatedly destroys safety or fidelity, the adaptation rule must be constrained.

---

# 9. Harm and unintended-consequence test

Every component must have an adverse-effect ledger.

Potential harms include:

- coercive premarital requirements;
- stigma;
- disclosure risk;
- partner surveillance;
- cultural stereotyping;
- norm enforcement;
- increased family pressure to marry or reproduce;
- digital privacy failure;
- volunteer burnout;
- referral overload;
- delay caused by unnecessary screening;
- false reassurance;
- over-medicalisation;
- displacement of state responsibility.

Define net value:

\[
NetBenefit
=
Benefit
-
Harm
-
OpportunityCost
\]

Kill rule:

\[
Harm \ge Benefit
\]

or violation of minimum safety/autonomy thresholds

\[
\Rightarrow
Stop/Redesign
\]

even if engagement or fertility indicators improve.

---

# 10. Opportunity-cost test

The question is not:

> “Does this intervention work?”

but:

> “Is this the best use of the next unit of resource?”

For the same budget compare:

\[
Navigation
\]

\[
Childcare
\]

\[
CashSupport
\]

\[
MentalHealth
\]

\[
ParentingSupport
\]

\[
CapacityExpansion
\]

\[
SafeSpace/Protection
\]

\[
Hybrid
\]

Use:

\[
IncrementalValue_k
=
\frac{\Delta MultiDomainOutcome_k}{\Delta Cost_k}
\]

Kill rule:

If the proposed civil-society layer is consistently dominated by another feasible allocation on outcomes that matter, it should not be preferred.

---

# 11. General-equilibrium and displacement test

Local success can create system failure.

Examples:

\[
Navigation\uparrow
\Rightarrow
Demand\uparrow
\Rightarrow
Queue\uparrow
\]

\[
VolunteerDelivery\uparrow
\Rightarrow
StateInvestment\downarrow
\]

\[
OneGroupAccess\uparrow
\Rightarrow
OtherGroupWaiting\uparrow
\]

Required evaluation:

- downstream capacity;
- waiting times;
- crowd-out;
- substitution;
- geographic redistribution;
- equity effects.

Kill rule:

A local improvement that worsens total system welfare or equity cannot be counted as unconditional success.

---

# 12. Level-of-analysis test

Do not move silently between:

\[
Individual
\rightarrow
Couple
\rightarrow
Family
\rightarrow
Community
\rightarrow
ServiceSystem
\rightarrow
Population
\]

Examples of prohibited collapse:

\[
IndividualReadiness\uparrow
\not\Rightarrow
TFR\uparrow
\]

\[
CommunityEngagement\uparrow
\not\Rightarrow
ChildOutcome\uparrow
\]

\[
ServiceUse\uparrow
\not\Rightarrow
PopulationWellbeing\uparrow
\]

Kill rule:

Any cross-level claim without an explicit aggregation mechanism must be removed or labelled speculative.

---

# 13. Temporal-decay and lag test

Effects may:

- appear late;
- decay;
- reverse;
- accumulate;
- emerge only at transitions.

For every outcome specify:

\[
Lag_k
\]

and:

\[
Decay_k
\]

where relevant.

Kill rule:

If the proposed mechanism predicts persistence but effects systematically disappear before the relevant life transition, the mechanism is inadequate.

---

# 14. Independent/adversarial challenge

At least one review round should be performed by people instructed to defeat the framework.

Their task:

1. choose the strongest rival explanation;
2. identify the weakest construct;
3. find contradictory evidence;
4. identify cultural counterexamples;
5. find cheaper substitutes;
6. find ethical harms;
7. state the observation that would make them reject the model.

Where feasible, proponents of rival interpretations should agree in advance on decisive tests.

---

# 15. Replication and prospective-registration test

After the conceptual paper, empirical studies should pre-specify:

- primary mechanism;
- primary outcome;
- boundary conditions;
- rival prediction;
- falsifier;
- stopping/harm rules;
- analysis alternatives.

Evidence becomes stronger when:

\[
Prediction_{before\ data}
\]

survives testing better than:

\[
Explanation_{after\ result}
\]

Replication should include different sites and cultural settings.

---

# 16. Parsimony test

The final model should be the smallest structure that still explains the important observations.

Let:

\[
Complexity(M)
=
NumberOfConstructs
+
NumberOfEdges
+
NumberOfFreeAssumptions
\]

Prefer a simpler model when:

\[
ExplanatoryGain
\le
ComplexityCost
\]

The purpose of mathematics, phenomenology and Toledo is to expose hidden distinctions—not to force every distinction into the final paper.

---

# 17. Positive evidence standard

“Positive attack” should not mean collecting confirming citations.

A relation gains support when several independent evidence routes converge:

\[
Triangulation
=
DifferentMethods
+
DifferentPopulations
+
DifferentDataSources
+
DifferentBiasStructures
\]

Strong positive support should ideally include:

- original/seminal conceptual source;
- recent synthesis;
- direct empirical test;
- replication;
- different context/population;
- mechanism-consistent observation.

A theory that survives only one research tradition remains fragile.

---

# 18. Final kill matrix

For every central relation, complete:

| Field | Requirement |
|---|---|
| Claim/equation | exact relation |
| Construct separation | not redundant |
| Measurement | valid/invariant enough |
| Positive evidence | strongest supporting evidence |
| Counterevidence | strongest contrary/null evidence |
| Rival model | simpler alternative |
| Causal threat | confounding/reverse causality |
| Boundary | where it should fail/change |
| Cross-context test | transportability |
| Specification test | alternate equations/analyses |
| Harm | possible adverse effect |
| Opportunity cost | best alternative use of resources |
| System feedback | downstream load/crowd-out |
| Prediction | risky prospective prediction |
| Falsifier | observation that defeats claim |
| Decision | retain / narrow / collapse / remove |

---

# 19. Theory-level stopping rules

The overall architecture should be substantially simplified or abandoned if several of the following occur:

1. central constructs cannot be distinguished empirically;
2. measures do not travel across contexts and no coherent local operationalisation is possible;
3. simpler rival models predict equally well or better;
4. key causal directions fail longitudinal/causal tests;
5. prospective distinctive predictions repeatedly fail;
6. central effects vanish across reasonable specifications;
7. benefits do not transport beyond narrow settings;
8. cultural adaptation consistently conflicts with safety/autonomy;
9. harms or inequities equal or exceed benefits;
10. alternative resource allocations dominate economically;
11. improved access mainly produces unmanageable capacity overload;
12. independent/adversarial reviewers can explain the evidence with a materially simpler architecture.

The framework is strongest when it contains its own instructions for being reduced or discarded.
