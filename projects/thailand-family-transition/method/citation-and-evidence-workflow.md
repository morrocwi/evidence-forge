# Citation and evidence workflow

## Purpose

The paper is conceptual, but the evidence process must still be reproducible enough to withstand claim-level review.

A systematic review is not required unless the paper explicitly claims to be one.

## Evidence layers

\`\`\`text
Structured literature search
        ↓
Integrative / problem-oriented synthesis
        ↓
Claim–Evidence Matrix
        ↓
Backward + forward citation chaining
        ↓
Claim-level citation audit
        ↓
Counterevidence + boundary audit
\`\`\`

## Structured search log

For every search family record:

- question/domain
- database/search engine
- exact query
- date searched
- language limits
- date limits
- document types
- inclusion rationale
- exclusion rationale
- number of high-priority sources retained

## Source hierarchy for important claims

For each major variable or mechanism, seek three evidence positions where possible:

\[
Seminal\ source
+
Current\ synthesis
+
Critical/contradictory\ evidence
\]

Reviews can map a field, but foundational claims should be checked against original sources where feasible.

## Claim–Evidence Matrix

Required fields:

| Field | Description |
|---|---|
| Claim ID | stable internal identifier |
| Claim / equation | exact statement |
| Variable / mechanism | what part of the system is involved |
| Seminal source | earliest/defining work where relevant |
| Current synthesis | recent review/meta-analysis/guideline |
| Direct support | what the source supports |
| Does not support | what must not be inferred |
| Counterevidence | null, contradictory or heterogeneous evidence |
| Population | population studied |
| Geography | study setting |
| Period | historical period |
| Boundary | when/where the claim may fail |
| Observable implication | what should be visible if claim holds |
| Falsifier | evidence that would materially weaken it |
| Manuscript section | intended use |

## Citation chaining

For high-value sources:

1. inspect references for earlier/seminal work;
2. inspect citing papers for later tests, critiques and replications;
3. record disagreements instead of choosing only confirming papers.

## Claim-level audit

Before manuscript use, ask:

- Does the source support this exact wording?
- Is the population the same?
- Is the time period relevant?
- Is an association being rewritten as causation?
- Is a review being cited instead of the original source unnecessarily?
- Is contrary evidence missing?
- Is the citation being used as a substitute for reasoning?

Rule:

\[
Citation \neq Argument
\]

## Equation audit

For each mathematical relation, record:

\`\`\`text
equation
→ empirical meaning
→ evidence supporting each term
→ evidence supporting the relation
→ counterevidence
→ boundary
→ falsifier
\`\`\`

A mathematically neat expression does not become empirically valid merely by being formalized.

## Search strategy by equation family

Search separately for:

- fertility and family policy
- financial support
- housing
- parental leave
- childcare
- work-care compatibility
- fertility literacy and preconception
- infertility and assisted reproduction
- relationship education
- programme dosage
- time scarcity / administrative burden
- access and take-up
- navigation and continuity
- religious premarital preparation
- intimate-partner violence
- reproductive coercion
- confidentiality / privacy
- mental health
- family well-being
- capability conversion
- caregiver/family load and resource depletion
- child development
- equity
- implementation
- re-entry / longitudinal access
- unintended harms

## Reporting discipline

Do not use PRISMA language unless a genuine systematic review has been performed.

Do not write “no evidence exists” unless the search scope justifies that claim.

Prefer:

> “The current structured search did not identify…”

when absence is search-bounded.

## Stop rule before translation

Do not translate the equations into polished general-language claims until each central relation has:

\[
support
+
counterevidence
+
boundary
+
falsifier
\]

This keeps the prose from becoming more confident than the evidence.
