# Mahidol adversarial review response — v4

This note maps the main vulnerabilities identified in the Mahidol-style adversarial review to concrete manuscript changes.

| Concern | Change in v4 |
|---|---|
| Contribution unclear relative to access/referral/premarital literatures | Added explicit contribution paragraph: the contribution is the **configuration of the premarital contact as a service interface**, not invention of referral, safety, preconception care, or relationship education. |
| Method too vague | Expanded method section using the project's documented evidence workflow: search families, source hierarchy, backward/forward citation chaining, claim-level audit, counterevidence and boundary checks. Also disclosed that a frozen database-level historical search log is incomplete, so the paper does not claim systematic-review completeness. |
| Child pathway too distal | Rewrote Section 7 as **“ระยะทางที่ไม่ควรข้ามขั้น”** and anchored it to Nurturing Care + Family Stress. Explicitly states premarital is not a direct child-development intervention. |
| “Private route” could imply safety by itself | Added safeguarding architecture: privacy/confidentiality, trained bounded first response, risk procedure, and protected referral. Replaced indiscriminate “screening” language with “เปิดโอกาสให้ระบุความต้องการหรือข้อกังวล.” |
| Intervention not operational enough | Added six candidate functions for pilots: orientation, need articulation, navigation, private access, referral, and re-entry. They are proposals to test, not a proven minimum package. |
| Thailand fragmentation claim too strong | Reframed as an evidence-bound statement: public evidence reviewed does not yet allow reconstruction of a national user pathway; this is not a claim that the whole Thai system is disconnected. |
| Falsifiability weak | Added five explicit conditions under which the architecture should be reduced, redesigned, or rejected. |
| Low-cost language overclaims | “Low cost” is not treated as a finding. The manuscript now says “มุ่งใช้ทรัพยากรเพิ่มเติมให้น้อย” and requires counting training, supervision, coordination, safeguarding, data, and downstream capacity. |
| Receiving services ignored | Added availability, connectivity, capacity, quality, and accountability/governance as receiving-system conditions; referral count alone is not success. |

## Editorial rule retained

The v4 manuscript keeps the Yaoharee-style spine:
- state the problem first;
- explain what the evidence can and cannot say;
- make the practical move visible;
- keep theory behind the prose;
- preserve uncertainty in ordinary Thai;
- use short memorable claims only where evidence supports them.
