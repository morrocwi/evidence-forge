# Compression recommendation after Evidence Attack Round 3

## Status

Working recommendation only.

Do not register this as a new Toledo equation until the source-of-record / formalisation route is run.

## What Round 3 removes from the visible theory

Do **not** keep these as independent theory constructs:

- experienced access;
- generic felt safety;
- tiered support;
- opportunity cost;
- transportability.

Do not keep broad "meaning coherence" unless it demonstrates incremental value beyond self-concordance / meaning-in-life / autonomy.

## What survives as dimensions, readouts or gates

### Effective possibility / conversion conditions

Retain five broad dimensions:

1. **Access**
   - actual/formal availability
   - perceived access
   - navigation
   - continuity/re-entry

2. **Time / burden**
   - temporal feasibility
   - workload
   - care load
   - treatment/administrative burden
   - patient time / opportunity cost

3. **Safety / autonomy**
   - privacy
   - confidentiality
   - private individual channel
   - perceived safety for disclosure
   - protected referral
   - autonomy threshold

4. **Culture / meaning**
   - cultural intelligibility
   - endorsed-values compatibility
   - language
   - belonging/legitimacy where relevant
   - never cultural conformity as success

5. **Capacity / continuity**
   - receiving-node capacity
   - service slack
   - referral completion
   - reenterability
   - bottleneck diagnosis

## Implementation objects outside the core state equation

Keep outside the core construct set:

- culturally embedded entry point;
- stepped / tiered support;
- Edge / Node / Hybrid decision rule;
- triggered re-contact;
- transportability gate.

These are **design/evaluation rules**, not latent state variables.

## Resulting conceptual spine

The visible paper can now be organized around:

```text
Structural Conditions
        ↓
Effective Possibility
        ↓
Family Capability
        ↓
Choice / Action
        ↓
Family / Child Outcomes
```

under a life-course dynamic and with fertility remaining distal.

## Strongest remaining project-specific questions

1. Can a family-transition contact function as a low-burden gateway to later support?
2. What is the minimum safe/orienting content when temporal feasibility is low?
3. Does adding a private individual channel to shared couple contact improve safety/help-seeking without creating unacceptable burden?
4. Does a reliable return route plus triggered re-contact outperform either front-loading or continuous universal follow-up on cost/useful uptake?
5. Can culturally meaningful entry points improve reach while maintaining autonomy, privacy and professional boundaries?
6. Can capacity-aware referral prevent better navigation from simply shifting unmet need into queues?

## Kill rule

If these remaining relations are fully explained by existing access, continuity, stepped-care, cultural-adaptation and implementation frameworks without producing a distinct prediction, design rule or measurable boundary condition, the final paper should present them as an **integrated application/synthesis**, not as a new theory.
