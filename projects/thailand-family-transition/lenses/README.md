# Analytic lens registry

This project intentionally allows multiple analytic lenses during development.

The final manuscript does **not** need to display all of them.

| Lens | Internal use | Final-paper rule |
|---|---|---|
| Mathematics / systems equations | expose collapsed variables, transitions, constraints and optimisation problems | retain only equations that clarify the target argument |
| Toledo | enforce non-collapse, dynamic state, capability, safety, repair and boundary discipline | translate into ordinary disciplinary language unless direct formalism is needed |
| Phenomenology | examine lived access, meaning, temporality, embodiment, felt safety and belonging | use only concepts needed by the target domain |
| Social science | institutions, inequality, service systems, culture, family, implementation | likely main public-facing language for current submission |
| Humanities | meaning, agency, normativity, cultural interpretation, lived experience | integrate where it strengthens explanation |
| Public health / child development | preconception, mental health, parenting, nurturing care, safety | use as empirical and outcome layer |
| Economics / operations | cost, capacity, marginal value, edge/node bottlenecks | retain where needed for minimum-cost claims |

## Rule

During development:

\[
MoreLenses
\rightarrow
MoreWaysToDetectCollapse
\]

During final writing:

\[
FinalLanguage
=
RelevantSubset(DevelopmentLenses,\ TargetDomain)
\]

Do not confuse a broad internal reasoning stack with the final paper's disciplinary identity.
