# evidence-forge

Evidence-first workspace for building scholarly articles before manuscript assembly.

## Core flow

```text
source
  -> evidence note
  -> claim
  -> synthesis
  -> article section
  -> manuscript
```

## Rules

1. Keep source-derived statements separate from inference.
2. Every claim should be traceable to a source note.
3. Preserve uncertainty, disagreement, and null findings.
4. Do not promote a design proposition into an established finding.
5. Keep research genre explicit: empirical research, academic article, integrative review, systematic review, concept analysis, policy/document review.
6. Draft the final manuscript only after the evidence map and section schema are stable.

## Repository map

```text
schemas/        reusable article and review structures
projects/       topic-specific evidence maps and synthesis
sources/        source registry and provenance notes
claims/         claim registry and evidence links
manuscript/     later-stage assembly only
```
